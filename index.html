Caso principal · Cliente: MYM Distribuidora · febrero 2025 a hoy

Un sistema de pedidos completo, hecho y mantenido por mí.

MYM es una distribuidora que necesitaba ordenar todo el circuito de sus pedidos. Diseñé el backend en Spring Boot, la web en React y la app Android en React Native con Expo, que hoy usan unas 65 personas.

También me ocupo de la infraestructura en AWS, el deploy automático con Docker y GitHub Actions, y el monitoreo con Grafana, Loki y Prometheus.

El problema más interesante: cuando un pedido queda parcial o cancelado, los productos que sobran en la camioneta se ofrecen a los próximos clientes. Si el producto estaba en el pedido original, se respeta el precio viejo. Si no estaba y hubo aumento, se cobra el nuevo.
